Ce qu'il fait

Sur le chantier

  • La journée en un appui. Le chantier est déjà rempli, 8 h par défaut.
  • Sans réseau, ça marche. Tout part quand le réseau revient.
  • Le planning dans la poche, avec l'adresse et le téléphone du client.
  • Les congés, les photos, le matériel qui manque : depuis le téléphone.

Au bureau

  • Le lundi sur une page. Une semaine, un clic.
  • L'export paie du mois, prêt pour le comptable.
  • Le planning envoyé sur les téléphones d'un clic.
  • Chaque chantier a son dossier : photos, devis, régie, rapport.

Comment ça se passe

  1. Un appel d'une demi-heure. Sans engagement.
  2. Une demi-journée chez vous : vos salariés, vos chantiers, l'application sur chaque téléphone.
  3. Le premier lundi, vous validez. On vous rappelle trois semaines plus tard.

Pour les entreprises du bâtiment de 3 à 25 salariés, tous corps de métier.
